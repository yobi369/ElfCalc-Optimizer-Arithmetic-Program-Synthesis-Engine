# Santa 2026 frontier programs

One valid program for each of the 1,000 puzzles, scoring **131,053** in dataset version 18.

- `submission.csv`: exact `id,program` submission format.
- `sources.csv`: per-puzzle instruction count and source lineage.
- `CREDITS.md`: original source credits and license information.

The author reports that each program was replayed with an exact validator. The portfolio combines public programs and graph-search polishing; 181 programs in the full dataset were attributed to the author's own search and solver, while the rest are credited to upstream sources.

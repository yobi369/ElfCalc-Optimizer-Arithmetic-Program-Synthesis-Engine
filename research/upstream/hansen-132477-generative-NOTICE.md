# Published generative solvers

The programs produced by this directory are generated locally from the official puzzle file. The default runner passes only puzzle IDs, seeds, targets and bounds to the selected solver. A trace is accepted only when explicitly supplied with `--own-trace`, and its hash is recorded. The Atlas entry point invokes the notebook's standalone mode with no program banks. No notebook cells are executed.

Its CP-SAT model chooses an acyclic set of arithmetic recipes, then tries physical register schedules. Copyright 2026 the original-source contributors on Kaggle account arsen123. The release grants Apache 2.0 for the original source and documentation named in its release manifest. Referenced third-party programs retain their own terms. The local shared-helper ranking estimates which old instructions become unnecessary when several outputs share a new value. ## Reproduce

Run the following from the project directory. Provide g++ with `--compiler` if it is not on PATH. Our Windows experiments used the pinned WinLibs GCC 16.2.0 x64 UCRT build under `work/gen/toolchain`. The release archive was checked against SHA-256 `db014a73b71907c6c778fd1c938056cddcae9023f89f8dfff7783d9e45baf975`. [Compiler Release](https://github.com/brechtsanders/winlibs_mingw/releases/tag/16.2.0posix-23.1.3-14.0.0-ucrt-r3)

```powershell
python -B generative/run_source.py konbu data/puzzles.csv work/gen/konbu-fresh.csv --jobs 4
python -B generative/run_source.py arsen data/puzzles.csv work/gen/arsen-fresh.csv --jobs 5 --batch 1
python -B generative/run_source.py atlas data/puzzles.csv work/gen/atlas-fresh.csv --jobs 7
python -B generative/run_source.py rudolph data/puzzles.csv work/gen/rudolph-fresh.csv --jobs 6 --config 12 .18 60 80 16 40 1 0 0 0 2 2
python -B generative/atlas_portfolio.py data/puzzles.csv work/gen/atlas-portfolio.csv submission.csv work/gen/atlas-fresh.csv work/gen/rudolph-fresh.csv
python -B generative/run_source.py atakan-whole data/puzzles.csv work/gen/whole.csv --own-trace submission.csv --limit 20 --jobs 2
python -B generative/run_source.py arsen-depth4 data/puzzles.csv work/gen/cuts.csv --own-trace submission.csv --limit 16 --jobs 2
python -B generative/atlas_portfolio.py data/puzzles.csv work/gen/spliced.csv submission.csv work/gen/rudolph-complete.csv --strategy bridge-splice
python -B generative/run_source.py trajectory data/puzzles.csv work/gen/joint.csv --own-trace submission.csv --limit 24 --jobs 2
```

The runner independently replays and validates every produced program, writes valid checkpoints during stream-based runs and records final hashes and parameters next to each output. Add `--resume-from` with the checkpoint's path to continue after an interrupted run. The official input and generated answers are local to this project.

The Atlas portfolio command takes only explicitly named local donors, validates each supplied row, and saves a complete replay-checked incumbent after each batch. Its report records the exact donor hashes and optimizations beyond their per-puzzle short-program union.

The native runner selects the conservative x86-64 instruction set on Windows. GCC 16.2 under MinGW emitted a 32-byte aligned AVX stack store into a 16-byte aligned caller stack in some native builds. The source hashes and flags both enter the compilation cache key.
